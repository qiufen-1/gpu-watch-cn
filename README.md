# 显卡观测站

公开网站： https://gpu.shenlii.cn

只看北京地区、京东自营的 RTX 5080 / RTX 5070 Ti，11 个候选品牌。网站本身不调用 AI；每天 09:00（UTC+8）由 GitHub Actions 发起采集，平台可能延迟。

## 当前状态

页面、筛选、历史比较、两张趋势图和每日发布工作流已实现。**尚未接入授权价格数据源，因此生产数据为空，不包含假价格、未经核实的京东自营商品或补造历史。** 定时任务在未配置数据源时保留当前文件，不代表正在成功抓取京东。

## 本地检查

Node.js 22，无第三方依赖。

```sh
node --test tests.mjs
node collect.mjs --build
```

用任意静态 HTTP 服务预览 dist，不要用 file:// 打开 ES module。构建仅发布 7 个静态文件；采集脚本和测试不进入网站。

## 接入真实价格：下一步

1. 进入京东联盟 https://union.jd.com 或京东开放平台 https://jos.jd.com ，按平台实际要求完成账号、应用及接口权限申请。**有账号不等于有商品价格接口权限**，能否获批以平台为准。
2. 获得权限后，按实际获批接口编写服务端适配器，输出 [feed-contract.md](docs/feed-contract.md) 规定的 JSON。当前仓库已实现 JSON 数据源接入与校验，未声称实现或测试过具体京东 API。也可使用有授权的数据供应商；本版本不包含付费服务购买。
3. 必须能证明京东自营身份、北京地区库存与价格适用条件。联盟推广价格不自动等于北京结算价。PLUS、券、国补无法核实时不能按这些优惠计算到手价；不能跨优惠叠加规则自行减价。
4. 在本仓库 Settings → Secrets and variables → Actions 配置 `GPU_FEED_URL`（HTTPS 地址）、可选 `GPU_FEED_TOKEN`（Bearer 凭据）。凭据只通过 GitHub Secrets 使用，不要放入源码、data.json、截图或聊天。
5. 在 Actions → Daily GPU prices and Pages → Run workflow 手动运行。核验原始商品页面与 JSON 一致，再开启实际日常使用。未配置时工作流仍可发布诚实的待接入状态。

不绕过京东登录或验证码，不要求用户提供京东 Cookie。只存商品公开报价；不要向 feed 写入账号、地址、订单或其他个人信息。网页会公开全部历史 JSON。

## 数据与比较口径

- 金额单位为整数“分”。每商品、每天、每种条件最多一条报价。
- 同条件比较；条件列表变化即视为另一口径。低于此前 30 个自然日已记录价格才标新低，首次只标开始记录；不假设每天都有数据。
- 当日最低价只使用当天已核实有货报价。未知库存、无货和过去报价不进入今日排名。
- 曲线是当日已覆盖商品最低价，不代表全网/京东全站最低；型号可能变化，空日期留空。
- 只接纳当天六小时内、与批次时间一致的报价；历史保留约 400 天。
- 采集失败保留历史、显示错误状态；历史存储在仓库 data.json，后续构建失败可从 Git 历史恢复。
- 不保证个人账号、地区补贴、付款方式优惠完整覆盖，不对未来价格作预测。

## 部署

GitHub Pages 选择 GitHub Actions，Custom domain 填 gpu.shenlii.cn；Cloudflare 为 gpu 设置 DNS-only CNAME 到 qiufen-1.github.io。证书签发后启用 Enforce HTTPS。根域和 ai 子域的记录不需要改动。

daily cron: `0 1 * * *`。GitHub 免费托管仍受平台使用额度与调度规则限制；长期无提交时定时任务可能被平台停用，应查看 Actions 状态。
